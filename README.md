# ALIS — Adaptive Laser Image System

Выпуски программы ALIS и прошивок контроллера установки прямого экспонирования
фоторезиста печатных плат.

**Исходников здесь нет** — только готовые файлы. Скачивайте их со страницы
[Releases](https://github.com/PavelSirotkin/ALIS/releases/latest):

- `ALIS.exe` — программа для Windows 10 (с 1607) и Windows 11; прошивки для
  обновления контроллера вшиты в неё;
- `ALIS_<плата>_V<версия>_factory.hex` — первая прошивка контроллера
  (загрузчик и прошивка вместе): F103C8 — через ST-Link, G431 — по USB через
  STM32CubeProgrammer;
- `README_RU.txt` — как ввести установку в работу (это `ЧИТАТЬ.txt` из поставки).

Дальше программа обновляется сама: при запуске она проверяет, нет ли новой
версии, и предлагает её скачать. Прошивку контроллера она предлагает обновить
при подключении станка.
